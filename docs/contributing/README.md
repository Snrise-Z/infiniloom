1. Read [CONTRIBUTING.md](../../CONTRIBUTING.md) for guidelines
2. Review the architecture in [INFINILOOM_DESIGN.md](INFINILOOM_DESIGN.md)
3. Run `cargo test --workspace` before submitting PRs
4. Follow the lint rules in [CLIPPY_GUIDE.md](CLIPPY_GUIDE.md)
